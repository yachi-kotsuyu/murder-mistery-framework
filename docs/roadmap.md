# 汎用マーダーミステリー制作フレームワーク・工程ロードマップ

## 1. マダミス制作の基本原則：射影（プロジェクション）モデル

マーダーミステリー制作において最も危険なのは、後半のテキスト（HOやカード）を先に書いてしまい、矛盾発覚時にドミノ倒しのように全修正が発生することです。
これを防ぐため、以下の順序律を厳格に遵守します。

> **【鉄則：作業の順序律】**  
> **第1層：客観（事件の真相）** ➔ **第2層：回路（証拠品・推理導線・ミスリード）** ➔ **第3層：主観（HO本文・演出）**

## 2. 汎用マダミス制作 5段階ロードマップ

| フェーズ | 対応項目 | 種別 | 具体的な作業内容・成果物 |
| :--- | :--- | :--- | :--- |
| Phase 1：コア仕様設計 | 1-1. 基本情報 | 共通固定 | プレイ人数、GM要否、プレイ時間、環境、基本スペック表の確定 |
| Phase 1：コア仕様設計 | 1-2. メインギミック | 可変カスタム | 体験目標（本格推理/ドラマ/思想等）、前提ルール・メインギミックを確定 |
| Phase 2：全体設計 | 2-1. 事件真相 | 共通固定 | 事件の真相（被害者・真犯人・動機・死因・現場偽装）を確定 |
| Phase 2：全体設計 | 2-2. メインタイムライン | 共通固定 | 事件発生時刻・強制イベント等のメインタイムラインを確定 |
| Phase 2：全体設計 | 2-3. タイムテーブル | 共通固定 | ゲーム全体の流れを確定 |
| Phase 3：情報・動線設計 | 3-1. 推理導線 | 共通固定 | 現場物証 ＋ 証言 ＋ 犯人の嘘 ＝ 真犯人特定「決定打の3点鎖」を定義 |
| Phase 3：情報・動線設計 | 3-2. ミスリード | 共通固定 | 他PC全員にやましい行動と現場カードを1対1で紐づけ（ノイズ配分） |
| Phase 3：情報・動線設計 | 3-3. 詳細タイムライン | 共通固定 | 各PCの時系列行動と物理的整合性（移動・すれ違い）の検証 |
| Phase 3：情報・動線設計 | 3-4. 固有ギミック | 可変カスタム | フェーズ進行に伴う演出・特殊スキルの流通設計 |
| Phase 3：情報・動線設計 | 3-5. 調査ルール設計 | 共通固定 | 調査コスト（AP消費）や情報開示制限のルール管理 |
| Phase 4：情報執筆 | 4-1. 全体ルール＆プロローグ | 共通固定 | タイムテーブル、世界観導入文、基本ルールの清書 |
| Phase 4：情報執筆 | 4-2. 手がかり・証拠品カード | 共通固定 | 全カードの表面（公開情報）と裏面（詳細調査）の清書 |
| Phase 4：情報執筆 | 4-3. キャラクターHO集 | 共通固定 | 配役バランス表、HO共通フォーマットに沿った個別HO本文執筆 |
| Phase 4：情報執筆 | 4-4. エンディング＆真相解説 | 共通固定 | 投票結果によるマルチエンディング分岐、真相解説スクリプトの清書 |
| Phase 5：検証・テストプレイ | テストプレイ＆検証 | 共通固定 | テストプレイ実施、ロジック・時間・得点バランス検証と修正反映 |

## 3. 「この作業を先にやっていいか？」の判断マトリクス

| やりたい作業 | 先行着手 | 判断理由・条件 |
| :--- | :--- | :--- |
| キャラクターの生い立ちや思想、口調の検討 | 〇 可能 | 世界観や人間関係のアイデア出しはPhase 1〜Phase 2のどの段階で進めても手戻りになりません。 |
| 骨格アンカー時刻（主要事件発生時刻）の策定 | 〇 可能 | Phase 2（事件真相）策定時に、全体の基準点として先行確定できます。 |
| 全体タイムテーブルの策定（2-3） | 〇 可能 | プレイ時間（1-1）と事件の枠組み（2-1、2-2）が決まっていれば、詳細設計前に確定可能です。 |
| 15分刻み詳細タイムラインのFIX | △ 条件付 | Phase 3の「3-2. ミスリード」と並行してすり合わせながらFIXする必要があります。 |
| 個別HOのタイムラインや秘密の執筆 | × 禁止 | Phase 3の「3-2. ミスリード」が終わる前に書くと、カードとの食い違いで必ず書き直しになります。 |
| 証拠品カードの解説文・フレーバー執筆 | △ 条件付 | Phase 3の「3-1. 推理導線」で決定打となるカードの役割が決まっていれば執筆可能です。 |
| プロローグや世界観導入文の執筆 | 〇 可能 | Phase 1（基本情報、メインギミック）が確定していれば、いつでも独立して清書できます。 |
| エンディング分岐テキストの執筆 | × 禁止 | 勝利条件や思想変容条件が定まる前に書くと、結末の選択肢と点数計算が噛み合わなくなります。 |
