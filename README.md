# 汎用マーダーミステリー制作フレームワーク・運用システム

本格的なマーダーミステリー（マダミス）作品の制作において、「中盤での手戻り」「設定矛盾による全員分の書き直し」「何から手をつけるべきか迷う停滞」を防ぎ、論理破綻のない作品をスムーズに完成させるための標準工程論（パイプライン）および制作テンプレートです。  
本フレームワークはあくまで汎用性を主軸において作成されているため、個々人の作法やシナリオの特性に合わせて適宜読み替えてください  

## 💡 コアコンセプト

### 1. 射影（プロジェクション）モデル
このフレームワークでのマダミス制作は、最初から各プレイヤーのハンドアウトは書きません  
「1つの客観的真実」 を作り、それを 「プレイヤーの推理回路」で切り分け、最後に「各キャラクターの主観」へ流し込む3層構造で進行します。  

【第1層：客観】 事件の真相
↓
【第2層：回路】 証拠品・推理導線・ミスリード
↓
【第3層：主観】 各キャラクター個別HO本文・主観時系列・演出

※ 第1層・第2層が固まる前に第3層に着手すると、矛盾発覚時に全面書き直しが発生するため、順序を徹底します。

### 2. 核心推理「決定打の3点鎖」
プレイヤーが勘やメタ推理ではなく論理で真犯人に到達できるよう、以下の3要素を必須の鎖として設計します。
1. 要素①【現場物証】：犯行現場に残された決定的な痕跡（凶器の入手経路、現場の残留物など）
2. 要素②【客観的証言】：第3者による目撃や状況証言
3. 要素③【タイムライン上の嘘・不整合】：犯人の供述やアリバイの崩壊点

## 🚀 使い方

1. templates/master-design-template.md をコピーして、自身の企画用ドキュメント（またはGoogle Docs/Notionなど）を作成します。
2. docs/roadmap.md に記載された「Gate通過チェックリスト」に従い、Phase 1 から順に埋めていきます。
3. 迷ったときはロードマップ内の 「この作業を先にやっていいか？判断マトリクス」 を参照し、手戻りのリスクを排除しながら進行します。
